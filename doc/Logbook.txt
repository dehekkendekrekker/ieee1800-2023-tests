===== 14-1-2026 =====
* Implemented functionality that takes an AST and transforms it into a datastructure that can be more easily handled.
* This datastructure is a Pathmap and is basically a Hashmap mapping rule names to their definition.
* This Pathmap describes all possible paths that can be taken from the entry point to the end of each path
* Implemented routine that takes this pathmap and enumerates each  individual path through the map.
* These path form the basis for code generation.

Caveat: In this process, the path space explodes and it is not sure if it is finite. It is safer to assume it is not and build controls to manage
this space.

It is through placing constraints on the pathmap that this is best done. Exactly how this is done should be scrutinized
